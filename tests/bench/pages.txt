# One page per line:  id  set  target  [option=value ...]
#   id      letters, digits and "-" (AmigaDOS file names: logs/<id>.log, png/<id>.png)
#   set     local   our own pages from this repository, no network
#           compat  feature probe and conformance pages
#           live    sites on the internet over https://, fetched read-only
#   target  a repository path (local pages) or an http(s):// address
#   options wait=N   seconds obcore-view lets the page load (default BENCH_WAIT, 120)
#           text=1   also print the page's text (OBVIEW_TEXT; Acid3's score)
#           lite=0   do not run OpenBrowser Lite's obfetch on it
#
# Live pages change from day to day: compare runs from the same day, or
# look at trends over several runs, never one live number on its own.
